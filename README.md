# AI Cover Letter Generator

This project is an AI-powered cover letter generator built with Angular. It uses various AI models to generate professional cover letters based on your resume and job description.

## Features

- **Multiple AI Providers**: Supports Perplexity AI.
- **Customizable Tone**: Choose between professional, casual, or formal writing tones.
- **Theme Support**: Light, dark, and system themes.
- **Download Options**: Download cover letters as TXT or Markdown files.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- Angular CLI (v17 or higher)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/coverletter_generator_ai.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd coverletter_generator_ai
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the Application

1.  Start the development server:
    ```bash
    ng serve
    ```
2.  Open your browser and navigate to `http://localhost:4200/`.

## Usage

1.  Enter your Perplexity API key.
2.  Select the AI model you want to use.
3.  Paste your resume and the job details.
4.  Click "Generate Cover Letter" to create your cover letter.
