# 🚀 Job Application Generator - Angular + Multi-AI

Generate professional cover letters using AI (OpenAI, Claude, Gemini, Perplexity).

## Quick Start

```bash
npm install
ng serve
# Open http://localhost:4200
```

## Features

- ✅ Multi-AI provider support
- ✅ Secure client-side API key storage
- ✅ Professional cover letter generation
- ✅ Download as .txt or .md
- ✅ Copy to clipboard
- ✅ Responsive design
- ✅ Dark mode support

## Deployment

```bash
# Production build
ng build --configuration production

# Deploy to GitHub Pages
npm run deploy

# Or use Netlify, Vercel, Docker
```
